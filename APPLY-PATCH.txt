IMPORTANT:
1. Preserve the folder structure when uploading. Merge the app/ folder with the
   existing app/ folder; do not replace the whole app source folder.
2. The owner panel needs owner-panel/firebase-config.js created from the Firebase
   Web App config for the SAME Firebase project as the Android app.
3. Set CLOUDINARY_API_KEY and CLOUDINARY_API_SECRET as Firebase Functions secrets.
   Never put either secret or service-account JSON in GitHub or in the Android app.
4. The owner account must be assigned the owner:true custom claim using the trusted
   Admin SDK script in scripts/set-owner-claim.js.
5. The current Android Store is still static. This patch supplies the panel/backend
   starter and fixes the missing Android resource references, but does NOT yet make
   the installed APK read storeItems or securely purchase/equip frames. That requires
   a separate MainActivity.kt Store migration.
6. Do not deploy restrictive Firestore rules until that Android wallet/store migration
   is complete; existing app code still writes wallet/cosmetic fields from the client.
